Mi proyecto: Tarea 2- Lenguaje de programacion 1- Estructuras de control repetitivas.


Breve descripción de qué hace este proyecto: Este proyecto cuenta con 5 ejercicios los cuales 
utilizan estructuras de control repetitivas, fue desarrollado para la asignatura lenguaje de programación 1.

📌 ¿Qué hace?
Explica aquí el propósito del proyecto.

1-Hacer un programa que imprima los numeros pares entre 0 hasta un número introducido por teclado. 
2-Hacer un programa que imprima la suma de los numeros que hay entre el 0 y un número introducido por teclado. 
3-Hacer un programa que imprima los numeros impares hasta un número introducido por teclado y cuantos impares hay. 
4-Hacer un programa que de un número introducido por teclado, imprimir el factorial. 
5-Hacer un programa que imprimir la tabla de multiplicar hasta el 10 de un número introducido por pantalla.
